## Wedge Stress-Test

**Paywall confirmed:** Square pricing page confirms "Cancellation policy and no-show fees" is Plus-only. Deposits feature placement is ambiguous in the fetched content but structurally consistent with Plus tier. Core wedge is directionally correct.

**Fresh incumbent search:** WebSearch budget was exhausted (0/200 remaining); could not run a fresh 2025–2026 search. This is a hard gap — rubric criterion (b) cannot be confirmed. No evidence was found that the gap has been closed, but absence of evidence is not evidence of absence given the budget constraint.

**Square App Marketplace:** Fetched but returned only introductory text; no deposit/prepayment plugin was surfaced. Developer API URL (developer.squareup.com) returned 404. Cannot confirm or deny the "requires Square partnership" claim for marketplace distribution.

**Alternative parallel-system claim:** Sources show users are frustrated and want the feature inside Square — but none explicitly name Acuity, Cal.com, Setmore, or others and say "I won't use it because of parallel system friction." The narrative is constructed by the claim; it is plausible but not cited-evidence-backed.

---

## Buildability Assessment

Pure web software that sits as a Square App Marketplace plugin requires Square OAuth + Appointments API + Payments API integration. The developer API 404'd; assuming the API exists (it is well-documented publicly as of training data), a one-person build in a month is plausible for a narrow MVP (deposit link on booking, Square payment flow). The marketplace partnership gate is a go-to-market friction point, not a technical blocker for an MVP.

## Kill Reasons

1. **Count mismatch:** "Nine named complainants" is inflated if you exclude Square Champions acting as helpers and an out-of-persona Capterra reviewer. Genuine independent beauty/salon complainants are 7–9; "nine" is at the top of a generous range, not a solid count.

2. **"Rejected all alternatives" is inferred, not cited.** No source shows a user saying "I tried Acuity/Setmore and won't use it because I'd need a parallel system." The rejection narrative is the claim author's construction.

3. **Plus plan price ($29–49/month) does not appear in the cited URLs.** It comes from the pricing page (not cited), so criterion (d) fails on this specific number.

4. **Three-year span is borderline.** Source 1 alone is only 2 years; the combined window is ~2.75 years stretched to "3."

5. **Fresh incumbent search could not be completed** (WebSearch budget exhausted). If Square has added a free-tier deposit feature or a third-party plugin has emerged in 2025–2026, the wedge collapses — this risk is unresolved.

---

## What Survives Skepticism

- Core pain (card holds failing, deposits paywalled) is real and confirmed by genuinely independent users across two live community threads and Capterra.
- The technical mechanism (clients freezing cards via banking apps) is explicitly stated by sgvaughan and corroborated by LusterSalon.
- The paywall structure (deposits/cancellation fees gated to Plus) is confirmed by Square's own pricing page.
- User reluctance to leave Square ecosystem is implied (HArmstrongSP: "forced to switch everything over"), even if not framed as "refusing parallel systems."

---

**Verdict: WEAK — pain is real and URLs check out, but the claim overcounts complainants, the "rejected all alternatives" assertion is unverified inference, key pricing numbers don't appear on cited pages, and the fresh incumbent search could not be run.**
