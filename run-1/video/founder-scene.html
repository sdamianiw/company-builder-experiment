Why I built this
I built BatchCOGS because that feature should cost $19 a month, not eighty-three.
Recipe-based auto-deduction is a basic accounting function for handmade sellers. The price should reflect that.
How it works
It connects to Etsy and Shopify.
You define a recipe for each product.
When an order comes in, your materials deduct automatically.
What gets logged
Every deduction is logged.
If something goes wrong, you correct it manually — and the change is recorded. Every correction is in the audit history.
One honest limit
New accounts start with CSV import while Etsy API approval processes. Webhook-based sync activates once access is granted.
